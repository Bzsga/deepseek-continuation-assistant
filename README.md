# Deepseek续聊助手

把旧聊天整理成可编辑、可追溯的续聊档案，再带回 DeepSeek 新会话。

作者：半盏丶时光  
由GPT-6制作

**Android 8.0+ · 源码 1.0.11（versionCode 20）· MIT**

这是独立开发的辅助工具，**不是 DeepSeek 官方应用，也不隶属于 DeepSeek**。实际聊天仍在 DeepSeek 官方应用或网页版中进行。

## 下载与使用

在 [GitHub Releases](https://github.com/Bzsga/deepseek-continuation-assistant/releases) 获取安装包和版本说明。当前作为早期测试版提供；安装时可能需要在 Android 系统中允许安装未知应用。

1. 在 [DeepSeek 网页版](https://chat.deepseek.com/) 下载聊天导出 ZIP，从浏览器下载列表或文件管理器分享给本助手，无需解压。应用首页提供分步教程，也支持手动选择文件。
2. 选择一段聊天，点击“开始智能整理”。着急继续时选“先快速接续”，在本机准备最近原话，无需等待模型；完整原文打包放在更多选项中。
3. 短文选择“复制并打开 DeepSeek”，长文先“保存续聊文件”再打开 DeepSeek，在官方新会话中粘贴或添加 TXT 文件。默认已准备续聊线索；需要时展开“调整与更多”。复制和保存都使用当前预览对应的完整文本，未完成进度的恢复入口保持可见。

已有安装可在“设置 → 关于”检查原版更新。[原版更新清单](https://digimonlegend.com/continuation-updates/latest.json) 与 GitHub 发布页面是不同的分发入口。

1.0.10起更新下载由Android系统管理，可切到后台，重新打开恢复同一任务；安装前仍校验完整性和签名。首次从旧版升级本次，请保持旧版在前台下载，或使用浏览器下载安装包。

## 能做什么

- 导入 DeepSeek ZIP/JSON、粘贴记录或使用合成示例，保留消息角色、分支和来源。
- 将所选消息整理为背景、人物、决定、近期话题和重要原话，区分用户陈述、建议与推测。
- 保留讨论进展、排除方案的理由、已确认和待定事项；根据当前填写内容和最近所选原话的中英文词面相关性，优先携带当前话题需要的记忆和互动示例。
- “没接上？调整一下”支持漏背景、重复讨论、理解偏差、语气陌生四类问题，在本机准备短修正材料，可选补充或贴回新回复，草稿不上传、不写入档案。
- “补入最近聊天”可直接导入最近导出的记录；核实同一来源的已保存消息与完整完成分段，跳过重复内容，只整理新增消息，保留手工修改、删除和固定。
- 智能整理时一并识别明确交流要求、后来修正、共同说法、未完话题，以及多条助手原话中可观察的回应方式，不增加额外模型请求。
- 续聊文本先放当前填写的交流要求、明确交流线索和默认最多 4 条代表回应方式，再放未完话题、必要记忆与原话。关键问答兼顾不同已有线索，保留提问和回应情境；明确修正集中按来源呈现，不自动把相邻记录当成互相覆盖。主流程无需填写人设表。详见 [使用说明](docs/conversation-continuity.md)。
- 长摘要默认为互动和最近话题预留空间，整条选择自动记忆；手填、固定资料与明确要求优先保留，未附带数量可见，也可选“带上全部记忆”。最近问答过长时使用有标记的原文句段节选，依据所选范围的真实停点提示怎样接续；末条未附带时明确说明。原文模式保持所选原文完整。
- 长文优先按完整问答分段，必要时带入少量此前已选原文，帮助理解指代和纠正。优先保留明确要求、约定、条件及未完话题；重复展示只在同一来源时点合并，不改原档案。
- 配套整理默认同时处理2段，逐段保存并按原顺序合并；暂停、取消和恢复保留已有结果。
- 配套服务启用自动备用时，响应慢或故障可切换已配置线路；页面按服务能力显示请求次数范围，每次实际派发均扣次。自己的 API 仍保持单线路，不自动换服务。
- 可选“生成温和版”：单独检查续聊文本中的政治敏感议题，查看命中原文和原因、保留误判段落后再复制或保存。原档案不变；点击“开始检查”才另行请求模型并正常计次或计费。
- 编辑或固定条目、查看来源、恢复历史版本，并保留已完成的分段结果。
- 在结果页或档案详情“重新整理”：确认原文范围、当前服务与预计次数或费用后，另存新版，保留原档案、手动修改、删除、固定内容和个人设置。范围无法恢复时明确重选；已有未完成任务优先继续。详见 [重新整理说明](docs/conversation-continuity.md#重新整理已有档案)。
- 复制或保存当前续聊版本，备份和恢复完整本地资料；可使用配套服务或自行配置兼容 API。

## 整理服务与费用

原版配套服务地址为 [continuation-api](https://digimonlegend.com/continuation-api)。免费整理同时受全站和个人每日次数限制，**以应用实时显示为准，不承诺永久有额度或持续可用**。长聊天可能分成多次请求；已经发出的失败或不确定请求也会计次。北京时间零点重置，排队取消可释放尚未使用的预留。

也可在设置中填写自己的 HTTPS Chat Completions 兼容接口、模型和 API Key。手机直接请求该服务商，费用与数据处理规则由该服务商决定。“测试连通”只发送短测试文本，也可能产生少量费用；保存设置本身不会开始整理。“生成温和版”是独立的可选检查，先显示实际分段的预计次数或费用；它不随普通整理自动运行，也不是免费的本地文本处理。

## 隐私与资料

导入、编辑、快速接续、修正材料和原文打包在本机完成。智能整理发送所选消息和必要的已选前段参考；主动开始“生成温和版”则发送当次续聊导出文本的分段副本。配套模式经过后端发送给上游，自己配置 API 时由手机直连。配套后端在任务终态 24 小时后清除任务正文与结果，仍保留计次和账务元数据；上游服务商有其独立保留政策。

失败/不确定的整理请求还会私有留存必要请求快照和原始有界回复，默认24小时，用于离线复现；成功请求不额外留存，不保存服务密钥或鉴权头。

密钥由 Android Keystore 保护，普通备份不包含服务密钥。反馈内容、联系方式、图片和受限技术诊断有独立的上传与保留规则，详见 [隐私说明](docs/privacy.md)。不要在公开 Issue 中附上未经脱敏的聊天、备份或密钥。

1.0.11 导出格式 6 备份，需要 1.0.11 或更新版本恢复，保留增量接续首段参考的精确原文范围；当前版本可读取格式 1–6。此前格式 5 保留长文参考和任务状态，需要 1.0.8 或更新版本恢复。温和版检查记录及保留选择只在当前设备保存，不包含在档案备份中。

- AI 摘要可能省略、误解或产生推断，请核对关键内容；来源校验不能保证语义完全正确。
- 温和版只检查政治议题，可能误判或漏检；不会自动清除个人隐私，也不能保证其他平台接受文本。
- 回应方式来自旧助手行为的观察，不等于用户认可、助手身份延续或关系承诺；当前手填说明和更晚的明确用户要求优先。是否更容易接着聊，仍需实际使用反馈。

- 单次聊天导入文件上限为 32 MiB。大型会话和备份仍受设备内存限制，没有任意规模恒定内存保证。
- DeepSeek 官方导出界面或格式可能变化；官方 App 接收文件的效果与设备、账户状态有关。

新建档案默认开启自动接续，旧档案及明确保存的关闭状态保持原样，升级不会自动重新请求模型。关闭自动回应方式后，已验证的自动回应方式不再导出，也不会回落到事实段；条目仍保存在档案中，手动修改和明确选择的原话继续受原有规则保护。手动确认“重新整理”会按当前服务重新请求并正常计次或计费；继续已有进度会保留本轮已完成部分。配套服务沿用默认2路并发、实现上限5路，自配API仍串行。已发布版本以 [GitHub Releases](https://github.com/Bzsga/deepseek-continuation-assistant/releases) 为准。
