## 下载与使用

在 [GitHub Releases](https://github.com/Bzsga/deepseek-continuation-assistant/releases) 获取安装包和版本说明。当前作为早期测试版提供；安装时可能需要在 Android 系统中允许安装未知应用。

1. 在 [DeepSeek 网页版](https://chat.deepseek.com/) 下载聊天导出 ZIP，从浏览器下载列表或文件管理器分享给本助手，无需解压。应用首页点击“导入聊天文件”，需要帮助时打开下载教程。
2. 选择一段聊天。简短会话默认“直接使用原文”，保留完整所选消息，无需模型；也可改用智能整理。免费智能整理需注册并登录，使用自己的 API 无需账户。长会话可智能整理，或用“先快速接续”在本机准备最近原话。
3. 短文选择“复制并打开 DeepSeek”，长文先“保存续聊文件”再打开 DeepSeek，在官方新会话中粘贴或添加 TXT 文件。结果页先显示保存状态和主要操作，随后默认展开“续聊内容”；标题右侧“工具”打开独立工具面板。长文保存与打开 DeepSeek、未完成进度恢复及版本导航留在主区；复制和保存都使用当前预览对应的完整文本。

“续聊记录”右上角点击“管理”，或长按一条记录，即可多选、全选并批量删除。确认后只删除所选记录及其历史，原始导入和未选记录保留；相关整理会停止。

已有安装可在“设置 → 关于”检查原版更新。[原版更新清单](https://digimonlegend.com/continuation-updates/latest.json) 与 GitHub 发布页面是不同的分发入口。

1.0.10起更新下载由Android系统管理，可切到后台，重新打开恢复同一任务；安装前仍校验完整性和签名。首次从旧版升级本次，请保持旧版在前台下载，或使用浏览器下载安装包。

## 能做什么

- 导入 DeepSeek ZIP/JSON、粘贴记录或使用合成示例，保留消息角色、分支和来源。
- 整理尽量保留原话，用“我、你、我们”回顾背景、人物、决定和近期话题，保留建议的归属、讨论理由及尚未确定的想法。
- 保留讨论进展、排除方案的理由、已确认和待定事项；根据当前填写内容和最近所选原话的中英文词面相关性，优先携带当前话题需要的记忆和互动示例。
- “没接上？”支持漏背景、重复讨论、理解偏差、语气陌生四类问题，在本机准备短修正材料，可选补充或贴回新回复，草稿不上传、不写入档案。
- “补入最近聊天”可直接导入最近导出的记录；核实同一来源的已保存消息与完整完成分段，跳过重复内容，只整理新增消息，保留手工修改、删除和固定。
- 智能整理时一并识别明确交流要求、后来修正、共同说法、未完话题，以及多条助手原话中可观察的回应方式，不增加额外模型请求。
- 新总结（协议12／BYOK v1.8）保留原话里的语气、犹豫和具体互动，减少报告口吻与重复说明；历史停点保留为背景，首次回应可先自然重新进入交流，不催促立刻续答旧问题。
- 续聊文本以用户对“你”继续说话的视角组织，简短带入交流线索、代表回应方式、未完话题、必要记忆与原话，不固定要求打招呼；填写的下一句话放在结尾。关键问答兼顾不同已有线索，保留提问和回应情境；明确修正集中按来源呈现，不自动把相邻记录当成互相覆盖。主流程无需填写人设表。详见 [使用说明](docs/conversation-continuity.md)。
- 首页以导入为主；结果页移除重复步骤条，保存状态和主操作之后提供“补入最近聊天”“没接上？”，再显示默认展开的续聊内容。预览右上“工具”集中续聊设置、短文保存、详细编辑、敏感处理及可用时的重新整理，操作后关闭面板，避免挤压预览；服务参数收进设置，备份恢复仍可直接找到。
- 长摘要默认为互动和最近话题预留空间，整条选择自动记忆；手填、固定资料与明确要求优先保留，未附带数量可见，也可选“带上全部记忆”。最近问答过长时使用有标记的原文句段节选，依据所选范围的真实停点提示怎样接续；末条未附带时明确说明。原文模式保持所选原文完整。
- 长文优先按完整问答分段，必要时带入少量此前已选原文，帮助理解指代和纠正。优先保留明确要求、约定、条件及未完话题；重复展示只在同一来源时点合并，不改原档案。
- 配套整理默认同时处理2段，逐段保存并按原顺序合并；暂停、取消和恢复保留已有结果。
- 配套服务启用自动备用时，响应慢或故障可切换已配置线路；页面按服务能力显示请求次数范围，每次实际派发均扣次。自己的 API 仍保持单线路，不自动换服务。
- 可选“去除敏感内容”：单独检查续聊文本中的政治敏感议题，查看命中原文和原因、保留误判段落后再复制或保存。原档案不变；点击“开始检查”才另行请求模型并正常计次或计费。
- 编辑或固定条目、查看来源、恢复历史版本，并保留已完成的分段结果。
- 在结果页或档案详情的“工具”中选择可用的“重新整理”：确认原文范围、当前服务与预计次数或费用后，另存新版，保留原档案、手动修改、删除、固定内容和个人设置。范围无法恢复时明确重选；已有未完成任务优先继续。详见 [重新整理说明](docs/conversation-continuity.md#重新整理已有档案)。
- 复制或保存当前续聊版本，备份和恢复完整本地资料；可使用配套服务或自行配置兼容 API。

## 整理服务与费用

原版配套服务地址为 [continuation-api](https://digimonlegend.com/continuation-api)。免费整理同时受全站和个人每日次数限制，**以应用实时显示为准，不承诺永久有额度或持续可用**。长聊天可能分成多次请求；已经发出的失败或不确定请求也会计次。北京时间零点重置，排队取消可释放尚未使用的预留。

注册采用用户名和密码，注册后获得默认每日免费次数。公开注册总人数由管理员调整；一次性邀请码不占公开名额，也不受该上限限制。后台可修改默认每日次数，并同步影响跟随默认的已有用户；个人每日上限和当天剩余也能单独调整。后台只列已注册用户，并提供仍有效、尚未使用的邀请码及完整复制入口。普通界面只显示个人次数。

也可在设置中填写自己的 HTTPS Chat Completions 兼容接口、模型和 API Key。手机直接请求该服务商，费用与数据处理规则由该服务商决定。“测试连通”只发送短测试文本，也可能产生少量费用；保存设置本身不会开始整理。“去除敏感内容”是独立的可选检查，先显示实际分段的预计次数或费用；它不随普通整理自动运行，也不是免费的本地文本处理。

## 隐私与资料

导入、编辑、快速接续、修正材料和原文打包在本机完成。智能整理发送所选消息和必要的已选前段参考；主动开始“去除敏感内容”则发送当次续聊导出文本的分段副本。配套模式经过后端发送给上游，自己配置 API 时由手机直连。配套后端在任务终态 24 小时后清除任务正文与结果，仍保留计次和账务元数据；上游服务商有其独立保留政策。

失败/不确定的整理请求还会私有留存必要请求快照和原始有界回复，默认24小时，用于离线复现；成功请求不额外留存，不保存服务密钥或鉴权头。

密钥由 Android Keystore 保护，普通备份不包含服务密钥。反馈内容、联系方式、图片和受限技术诊断有独立的上传与保留规则，详见 [隐私说明](docs/privacy.md)。不要在公开 Issue 中附上未经脱敏的聊天、备份或密钥。

账户只用于身份与额度管理，续聊记录仍保存在本机。登录会话加密保存在当前设备，不进入资料备份；退出登录不删除本地记录。使用自己的 API、原文接续和本地编辑无需登录。

当前继续导出格式 6；含 v1.7 或 v1.8 整理任务的备份请用 1.0.13 或更新版本恢复，v1.6任务需要1.0.12及以上。格式6原有内容需要至少 1.0.11，保留增量接续首段参考的精确原文范围；当前版本可读取格式 1–6。此前格式 5 保留长文参考和任务状态，需要 1.0.8 或更新版本恢复。温和版检查记录及保留选择只在当前设备保存，不包含在档案备份中。
