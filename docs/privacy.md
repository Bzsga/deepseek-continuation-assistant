# 隐私与数据说明

本说明描述当前源码和原版客户端的处理方式。自行部署或使用第三方 API 时，还需查看实际服务运营者与上游服务商的政策。

## 本机资料

导出的 ZIP/JSON、导入会话、续聊档案、修订历史和任务片段保存在应用私有存储。导入、编辑、查看、原文打包与普通导出不调用模型。外部分享使用系统授予的 `content:` URI 读取权限，不申请全盘访问权限。

普通备份包含聊天资料和档案，**应当视为敏感文件**；不包含 API Key、匿名/管理员会话凭据等密钥。恢复前有确认，并会替换本机资料。1.0.9 继续写出格式 5 备份，需要 1.0.8 或更新版本恢复；当前版本读取格式 1–5。续聊预览中的记忆精简或原话节选不删改原档案与完整备份。

“清除本地资料”删除导入原件、会话、档案、历史、任务、分块缓存及温和版检查记录，保留服务配置与身份。它不会删除已经发送到外部服务的数据，也不会删除用户另外保存或分享的备份与续聊文件。

## 智能整理

仅所选消息、其中用于跨段理解的少量前文及必要来源信息进入整理请求：

| 模式 | 数据去向 | 凭据 |
| --- | --- | --- |
| 配套服务 | 手机 → 配套后端 → 后端配置的模型服务商 | 手机保存匿名会话，上游密钥留在服务端 |
| 自己的 API | 手机 → 用户配置的服务商 | API Key 通过 Android Keystore 保护 |

选择“开始智能整理”才开始此类请求。连接测试只发送固定短文本，不发送聊天。模型请求可能收费；失败、超时或结果不确定不代表服务商没有处理请求。

配套后端在任务终态起 24 小时后使正文与整理结果过期，并由清理器删除；停机期间到期的数据在恢复时清理。任务标识、内容摘要、状态、计次、用量和账务元数据仍保留，用于幂等与统计。成功请求不额外留存原始模型响应。测试期为排查失败/不确定请求，服务器另在私有诊断库保存选定分段的请求快照与有界原始上游响应，默认保留24小时（自托管可关闭或配置期限）；去除已知服务密钥，不保存鉴权头。原始响应可能包含上游返回的推理字段。诊断副本仅供受限运维按编号排障、离线重放，没有公网读取接口，过期拒读并清理。该规则不控制上游服务商或运营者另行制作的备份。

## 可选的政治议题检查

“生成温和版”检查的是当次保存的续聊导出文本，可能包含摘要、手填说明和已选原话。打开入口只准备范围和预计次数；点击“开始检查”才按上表相同路线分段发送给当前模型服务，正常计次或计费。它不随智能整理自动运行，不检查未选择的其他档案。

模型只标记可能涉及政治敏感议题的原文片段与原因，不负责改写剩余文字。默认导出时省略命中片段，可以勾选保留误判内容；原档案不被修改。检查不用于推断用户政治观点，也不是个人信息清理工具；结果可能误判或漏检，不能保证外部平台接受。

文本快照、检查进度和保留选择存于当前设备的应用私有存储，不在普通档案备份中；服务凭据仍由安全凭据存储保护。配套后端沿用任务正文、结果和失败诊断的到期规则。关闭窗口不清除进度；清除本地资料会删除检查记录，但已经派发到服务方的请求仍可能消耗次数或费用。

## 技术诊断

客户端会保存并有界补传技术事件，包括应用版本、Android SDK/设备型号、固定处理阶段、大小/耗时/内存指标、受限异常类和代码栈位置。白名单不允许聊天或模型正文、原异常消息、文件名、URI、联系方式、密钥和 bearer。

本机诊断最多 64 条、256 KiB、30 天；服务端按接收时间保留 30 天。上传使用现有匿名身份，确认收到后删除本机对应事件，不调用模型或消耗整理次数。首次导入失败时，符合配套模式及原版地址条件的客户端可自动创建匿名身份以补传。详情见 [诊断协议](diagnostics.md)。

## 意见箱

提交反馈会上传用户填写的正文、QQ/微信联系方式和所选图片。图片会缩小、重编码并移除原始元数据；图片中可见的文字或人像不会自动遮挡。

管理员能查看反馈与联系方式。受限处理者只能读取已批准的反馈内容、批注与图片，不能读取联系方式或管理配置。反馈不适用整理任务的 24 小时删除规则，当前没有自动到期删除机制。详见 [意见箱协议](feedback.md)。

请勿提交与问题无关的私人聊天或凭据；需要删除服务端反馈时，应联系所使用服务的运营者。

## 更新与公开反馈

版本检查和 APK 下载访问更新站点，不携带聊天或整理服务凭据，也不消耗模型额度。网络服务仍可能接收到 IP 地址等正常连接信息。

在 GitHub Issue、截图或日志中公开的信息可能被任何人读取。报告问题前请去除聊天正文、备份、账户信息和密钥。MIT 许可不要求提供这些私人数据。
