# 技术诊断协议

客户端记录导入、解析、保存、整理提交/轮询/恢复及未捕获异常的受限技术事件。允许字段包括版本、Android SDK/设备型号、固定阶段、尺寸/耗时/内存数值，以及受限异常类和代码栈位置；不接受聊天或模型正文、原异常消息、文件名、URI、联系方式、密钥或 bearer。

## 本机与上传

本机私有 no-backup 目录最多保留 64 条、256 KiB、30 天记录。未捕获异常尽力落盘后仍交给系统原异常处理器；内存耗尽、断电或系统终止可能没有完整日志。未完成的操作本身不能证明发生崩溃。

有既有匿名凭据时，在前台及完成/失败后有界补传。首次导入失败且无身份时，仅在配套模式及原版服务地址条件下复用匿名身份创建流程。离线保留本机，服务端确认事件 ID 后才删除；重复上传幂等。不调用模型、不消耗整理次数，也不切换用户的自配 API。

## HTTP 接口

- `POST /v1/diagnostics`：现有匿名 bearer，body 为 `{events:[...]}`，每批最多 20 条、32 KiB，每身份北京时间每日最多 1000 条。
- ID 为 UUID，时间为 Unix 秒；kind/stage、metrics、exception_class、stack_frames 均受双端白名单约束，未知字段拒绝。实际类型以 `backend/app/diagnostics.py` 为准。
- ACK `accepted_event_ids` 包含新接收、相同内容重复及已过 30 天的事件；同 ID 不同内容拒绝，过期数据不重新落盘。
- `GET /v1/admin/diagnostics?limit=100&since=<Unix秒>`：仅管理员可读，最多 200 条，不向受限反馈 worker 开放。
- 服务端独立保留 30 天，按接收时间清理，不修改整理任务或账务。

## 模型错误诊断

模型请求诊断只保留处理阶段、耗时、状态、返回尺寸、正文/思考的类型与字节数、上游报告的有界 token 数及 JSON 错误位置。提示版本 `prompt_version` 只允许整数 2 或 3。

JSON 结构探测仅报告首字符类别、不可见前缀标志、对象/数组候选存在性、最多两个完整候选及扫描是否受限。扫描有字符数、深度和尝试次数限制，不返回候选文本、键名或原字符；发现候选不代表接受该片段。

这些元数据能缩小排查范围，但不能还原被丢弃的原始回复。偏移 0 错误不能单独证明截断、网关替换或提示注入；网络失败也不一定是超时。

## 运维读取边界

`tools/runtime_watch.py` 提供只读白名单报告，可由运营者在受信任环境运行；远程入口须显式提供自己的可信 SSH helper。源码不包含生产凭据或已启用的调度任务。

移动事件按 `received_at` 增量读取，并保留实际发生时间，以识别离线补传。正常活动、明确错误和恢复线索分开记录。采集不完整或截断时不得将报告当作完整覆盖；旧客户端未记录的故障无法补造历史堆栈。不要通过读取私人聊天或重放结果不确定的收费请求补充诊断。
